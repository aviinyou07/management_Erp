# 🚀 Base URL

```
http://localhost:5000/api
```

---

# 👤 USER APIs

## 1️⃣ Get User Profile

```
GET /api/users/profile/:id
```

Example

```
GET /api/users/profile/1
```

Response

```json
{
"id":1,
"name":"Rishu",
"country":"India",
"badge":"NRI Hiring",
"followers_count":0
}
```

---

## 2️⃣ Follow User

```
POST /api/users/follow/:id
```

Example

```
POST /api/users/follow/2
```

Body

```json
{
"userId":1
}
```

Meaning:

```
User 1 follows User 2
```

---

## 3️⃣ Unfollow User

```
POST /api/users/unfollow/:id
```

Body

```json
{
"userId":1
}
```

# 📝 POST APIs

---

## 4️⃣ Create Post

```
POST /api/posts/create
```

Body

```json
{
"user_id":1,
"content":"Hiring MERN Developer",
"tags":["mern","hiring"]
}
```

---

## 5️⃣ Get Single Post

```
GET /api/posts/:postId
```

Example

```
GET /api/posts/1
```

---

# 🌎 FEED APIs

---

## 6️⃣ Country Feed

Shows posts from **same country users**

```
GET /api/posts/feed/country
```

Query

```
?userId=1&page=1&limit=10
```

Example

```
GET /api/posts/feed/country?userId=1&page=1&limit=10
```

---

## 7️⃣ Worldwide Feed

Shows **all posts**

```
GET /api/posts/feed/worldwide
```

Example

```
GET /api/posts/feed/worldwide?page=1&limit=10
```

---

## 8️⃣ Following Feed

Shows posts from **people you follow**

```
GET /api/posts/feed/following
```

Example

```
GET /api/posts/feed/following?userId=1&page=1&limit=10
```
